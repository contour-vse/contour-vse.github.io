Contour TestPrep, Tutor Guide

How to Run Contour Live Tools

Scan a QR on the class computer to open that tool's tutor screen. Students join on their phones with the room code.

No Device? No Problem

Writing Board: Add from Paper. Marker Match: Add Paper Marks. Prompt Feud: Type a Guess Said Aloud.

Names Stay Private

In the writing tools students see made up names like Teal Fox. Real names only show on your screen when you switch Names on.

Projector Screen

Open Projector screen from the tutor controls. It shows the game without names or your marks.

Contour TestPrepLeaderboards reset each lesson. Writing Board stars carry across the term on the Term Ladder.
